# BPG Nino Mtavruli

Georgian font family by Besarion Gugushvili (BPG-InfoTech), as credited in the upstream font.json. Unmodified WOFF2 files downloaded on 2026-09-21:

- Regular: https://github.com/web-fonts/bpg-nino-mtavruli/blob/master/fonts/bpg-nino-mtavruli-webfont.woff2
- Bold: https://github.com/web-fonts/bpg-nino-mtavruli-bold/blob/master/fonts/bpg-nino-mtavruli-bold-webfont.woff2

The upstream repositories identify the font-file license as Creative Commons Attribution-NonCommercial-NoDerivatives 4.0 (CC BY-NC-ND 4.0). The MIT license mentioned by the packages covers their code, not the fonts. See LICENSE.txt and https://creativecommons.org/licenses/by-nc-nd/4.0/.

These font assets are included for this internal prototype. Commercial deployment needs appropriate rights for the fonts; their inclusion here does not grant commercial permission.

CSS applies BPG to Georgian glyphs only. Latin text uses Plus Jakarta Sans, and unsupported Georgian characters fall back to Noto Sans Georgian. Regular and bold are separate static faces; no font files or stored user text were modified.
